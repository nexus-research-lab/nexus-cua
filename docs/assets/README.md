# Nexus CUA artwork

`nexus-cua-icon.png` is the repository's product icon. It combines the Nexus
family's violet-blue pangolin and frosted tile with a desktop window and cyan
pointer to identify computer use. The white N badge preserves the family mark.

The icon was generated with OpenAI image generation using the Nexus desktop
app icon as a visual reference. It is original product artwork, not a screenshot
of the runtime or evidence of platform support. Keep its square aspect ratio
and use descriptive alt text when embedding it.

The native fixture is a development test application; this asset does not
change its application bundle or imply a separate end-user agent product.
